# Hostel Application Portal (MERN)

A small full-stack app for submitting and viewing hostel applications.

## Features

- Add an applicant through a form (`AddApplicant`)
- View all submitted applicants (`ViewApplicant`)
- Express REST API storing applications in MongoDB

## Tech stack

**Frontend:** React · React Router · Bootstrap · Axios
**Backend:** Node.js · Express · MongoDB / Mongoose

## Getting started

Requires MongoDB running locally (`mongodb://127.0.0.1:27017/hostelApplication`).

```bash
cd backend && npm install && npm start
cd frontend && npm install && npm start
```
